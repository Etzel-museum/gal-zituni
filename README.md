# אתר גל זיתוני – אילוף כלבים

דף נחיתה סטטי (HTML/CSS/JS בלבד, בלי שרת ובלי התקנות). פותחים את `index.html` בדפדפן וזהו.

## איפה עורכים תוכן?

**רק בקובץ `js/content.js`.** כל טקסט, ביקורת, תמונה, סרטון ופרט קשר נמצאים שם. לא צריך לגעת ב-HTML.

| מה רוצים | איפה בקובץ |
|---|---|
| טלפון, אימייל, אזור, שעות | `business` |
| נוסח ההודעה בוואטסאפ | `business.whatsappMessage` |
| אינסטגרם / פייסבוק / טיקטוק / ביקורות גוגל | `social` |
| תמונות הרקע המתחלפות | `backgroundImages` |
| כותרת ראשית | `hero` |
| טקסט "עליי" + תמונה של גל | `about` |
| סרטון | `video.youtubeId` (או `video.file`) |
| ביקורות | `reviews.items` |
| שאלות נפוצות | `faq.items` |
| סדר החלקים בדף / הסתרת חלק | `order` |
| פרטי רכז הנגישות | `accessibility` |

### מצב טיוטה (`draftMode`)
- `true` – כל מה שעוד חסר מוצג במסגרת צהובה מקווקוות עם הסבר מה להשלים. הביקורות לדוגמה מוצגות עם תווית "דוגמה".
- `false` – חלקים ריקים נעלמים, הביקורות לדוגמה לא מוצגות, ההערות הצהובות נעלמות.
- **לפני פרסום – להעביר ל-`false`.**

### דוגמאות

הוספת ביקורת:
```js
{ name: "מיכל כ.", dog: "לוקה, גולדן בן שנה", rating: 5, text: "גל עשה לנו סדר בבית..." },
```

הוספת סרטון יוטיוב – מהקישור `https://www.youtube.com/watch?v=AbC123xYz` לוקחים רק את `AbC123xYz`:
```js
youtubeId: "AbC123xYz",
```

הוספת תמונה לגלריה (שמים את הקובץ בתיקייה `images/`):
```js
images: [ { src: "images/training1.jpg", alt: "גל מתרגל הליכה ברצועה עם כלבה לבנה בפארק" } ]
```

## נגישות – מה כבר קיים ומה צריך לשמור
קיים: מבנה כותרות תקין, ניווט מקלדת, "דילוג לתוכן", ניגודיות AA, עצירת התמונות המתחלפות, כיבוד "הפחתת תנועה", תפריט נגישות, הצהרת נגישות (`accessibility.html`), התאמה לנייד.

כשמוסיפים תוכן:
- **לכל תמונה עם משמעות – לכתוב `alt`** שמתאר מה רואים בה.
- **לסרטון עם דיבור – חייבות כתוביות** (ביוטיוב: להעלות/לאשר כתוביות בעברית; בקובץ מקומי: קובץ ‎`.vtt` ב-`video.captions`).
- לעדכן את תאריך העדכון ופרטי הרכז בהצהרת הנגישות.
- תפריט הנגישות לבדו לא "מנגיש" אתר – מה שקובע זה שהתוכן עצמו נגיש. אם רוצים אישור רשמי, אפשר לבקש בדיקה ממורשה נגישות שירות.

## תמונות הרקע
כרגע יש תמונות זמניות מ-Unsplash (רישיון חופשי). עדיף להחליף בתמונות אמיתיות של גל עם כלבים:
1. לשים את הקבצים בתיקייה `images/` (רוחב ~1920px, משקל עד ~400KB לתמונה).
2. לעדכן ב-`backgroundImages`: `{ src: "images/hero1.jpg", position: "center" }`.

## ברקוד עם הלוגו
`tools/qr.html` – מייצר ברקוד שמוביל לאתר, עם הלוגו במרכז. אפשר להוריד אותו כ-PNG להדפסה או כ-SVG. הכתובת נלקחת מ-`business.siteUrl`.
**להדפיס רק אחרי שהכתובת הסופית נקבעה, ואחרי בדיקת סריקה בטלפון.**
הלוגו הנוכחי (`images/logo-mark.jpg`) נחתך מצילום של כרטיס הביקור. אם יש קובץ מקורי של הלוגו, עדיף להחליף בו.

## פרסום
לפני פרסום: `draftMode: false`, ולמחוק את השורה `<meta name="robots" content="noindex">` מ-`index.html`.
אפשר להעלות את כל התיקייה כמו שהיא ל-GitHub Pages / Netlify / כל אחסון סטטי. אחרי שיש כתובת – לעדכן `business.siteUrl`.
